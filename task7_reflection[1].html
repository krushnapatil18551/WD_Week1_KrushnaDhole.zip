Week 1 Reflection & Learning

During Week 1, I learned the fundamentals of HTML and how a webpage is structured from the HTML5 document declaration to the head and body sections. I learned how to use headings, paragraphs, formatting elements, links, images, lists, tables, and forms. I also understood the importance of attributes such as alt, href, src, type, name, and required. The most challenging topic for me was creating forms because I had to understand different input types, radio buttons, checkboxes, dropdown menus, and labels. I enjoyed working with links, lists, tables, and semantic HTML because these elements made the webpage more organized and meaningful. I also enjoyed combining different concepts in the mini project and seeing how individual HTML elements work together to create a complete webpage. HTML will help me in learning web development because it provides the basic structure on which CSS and JavaScript are later added. By understanding HTML properly, I can create accessible, well-structured, and user-friendly webpages and move confidently toward frontend development.
